# ⚡ Apex Tracker — Habits & Study (100% Offline)

A **professional, fully offline** habit & study tracker that runs entirely in the browser.
No server, no account, no internet needed. All data stays on your device.

## ✨ Features

| Area | Details |
|---|---|
| 📅 **Daily Record** | Check-off habits, count targets (e.g. 8 glasses of water), time targets (e.g. 60 min study), daily journal notes, streak flames |
| 🗓 **Weekly Record** | Interactive 7-day grid, weekly completion %, best day, perfect days, focus time |
| 📊 **Weekly Report** | One-click professional report: per-habit breakdown, day-by-day table, consistency analysis, insights + Print/Save-as-PDF |
| 🗓 **Monthly Record** | Color-coded heatmap calendar, monthly stats, leaderboard, click any day to edit its record |
| 📈 **Statistics** | 30-day trend chart, category donut, habit scoreboard (current & best streaks), subject-wise focus time |
| ⏱ **Focus Timer** | Pomodoro (custom work/break/rounds), sound alert, sessions auto-logged and linked to habits |
| 🔐 **Security** | Optional 4-digit PIN lock (stored as SHA-256 hash, never plain text) |
| 💾 **Zero data loss** | Instant auto-save, 6 automatic snapshots (restore/download), JSON backup export/import (merge mode), CSV export for Excel |

## 🚀 How to Use

**Option A — Just the file:** download `index.html` (or the release zip), double-click it. Done. Works offline forever.

**Option B — Live web app (GitHub Pages):** this repo is deployable as-is (see below), then install it on your phone/desktop as an app (PWA).

### Install as an app (PWA)
- **Android:** open the hosted link in Chrome → ⋮ → *Install app* / *Add to Home screen*
- **iPhone:** open in Safari → Share → *Add to Home Screen*
- **Desktop:** Chrome/Edge → install icon in address bar



## 🔒 Privacy

Everything (habits, records, notes, sessions, backups) is stored **only** in your browser's localStorage on your device. Nothing is ever uploaded anywhere. Take JSON backups regularly from *Settings → Export*.

### استعمال کیسے کریں؟
1. `index.html` فائل ڈاؤن لوڈ کریں
2. اس پر ڈبل کلک کریں — کسی بھی براؤزر (Chrome/Edge/Firefox) میں کھل جائے گی
3. Settings → **Load Sample Data** سے ڈیمو دیکھیں، پھر اپنے habits بنائیں
4. ہفتے کی رپورٹ: **Weekly Record → Generate Weekly Report** (پرنٹ/PDF بھی کر سکتے ہیں)

### ڈیٹا محفوظ کیسے رہے گا؟

- **Settings → Export Backup** سے JSON فائل ڈاؤن لوڈ کریں اور USB/Google Drive میں رکھیں
- PIN لگائیں: Settings → Security → Set PIN
